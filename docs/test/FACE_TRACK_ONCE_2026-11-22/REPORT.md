## 7. Tái lập và trạng thái bàn giao

Script chạy thật: [runner](../../../tools/scripts/face-track-once-eval.mjs), [suite gốc](../../../tools/scripts/face-track-once-suite.mjs), [suite sau sửa timestamp](../../../tools/scripts/face-track-once-aligned.mjs), [tổng hợp](../../../tools/scripts/face-track-once-summary.py). Chạy trong root repository qua `node tools/scripts/face-eval-run.mjs ...` để sử dụng môi trường dev đã cấu hình, không in secret. Fixture/backup riêng nằm trong thư mục ignored `artifacts/face-track-once-2026-11-22`; không nằm trong ZIP.

Các action enroll/delete tác động collection QA thật; chạy case người lạ trước khi đăng ký B. Suite gốc hiện có thêm control Video 3 trước/sau xóa cho lần tái lập tiếp theo; lịch sử lần chạy thực tế được giữ trong suite log và RESULTS, không suy ra đã chạy một bước chỉ từ code script hiện tại.

Caddy/Cloudflare và backend dev phục vụ callback vẫn là tiến trình tạm thời; Quick Tunnel phải được cập nhật URL nếu khởi động lại. Không đưa AWS key, INTERNAL_SERVICE_TOKEN, mật khẩu, JWT secret, package backup Lambda hay toàn bộ dataset vào bộ bàn giao.
